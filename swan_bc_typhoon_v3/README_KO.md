# SWAN B·C 및 2021년 태풍 평가 v3

이 패키지는 현재 서버의 완료된 A와 기존 B를 이용합니다. 학습 모델, 손실함수,
데이터 분할, 방향 보정, 정규화 코드는 수정하지 않습니다. 기존
`swan_repaired_v1` 및 `swan_iclr_campaign_v2` 설치가 필요합니다.

## 변경 내용

- A 29건과 파일럿 9건의 검증된 완료 결과를 재사용합니다.
- 기존 B 12건의 계획을 그대로 유지합니다. 완료된 B는 재학습하지 않습니다.
- 모델별 B 4건이 모두 끝나면 파일럿 seed 42, A, B 중 검증 Hs MAE가 가장 낮은
  설정을 고정합니다. 테스트 RMSE, 2021년 결과, 학습시간은 선택 점수에 쓰지 않습니다.
- FNO와 FFNO의 B가 끝났다면 해당 C를 남은 TNO B와 병행합니다.
- C는 고정된 설정의 seed 43, 44를 실행합니다. seed 42는 선택된 기존 결과를 씁니다.
  파일럿이 선택되면 이미 완료된 파일럿의 세 시드를 재사용합니다.
- 기존 C가 동일한 작업으로 이미 완료됐으면 재사용하며, 같은 작업 폴더가 있으면
  그 폴더에서 재개합니다. 새로운 C 결과는 별도 폴더에 저장합니다.
- D, E를 실행하지 않습니다. 추가 w/d/m 또는 학습률 후보를 생성하지 않습니다.
- 9개 선택 결과가 모두 확인되면 2021년 평가와 사건 분석을 자동 실행합니다.

TNO 128/6을 임의로 우선 선택하지 않습니다. 256/4의 검증 MAE가 가장 낮다면
256/4가 선택됩니다. 시간 상한으로 선택 기준을 바꾸려면 본 실행 전에 별도 결정을
해야 합니다. 현재 패키지는 합의한 검증 성능 기준을 유지합니다.

## 설치와 실행

ZIP을 `/home/jovyan/swan/`에 업로드한 뒤 다음 명령을 실행합니다.

```bash
cd /home/jovyan/swan
unzip SWAN_BC_Typhoon_v3.zip
nohup bash /home/jovyan/swan/swan_bc_typhoon_v3/START.sh > /home/jovyan/swan/iclr_bc_typhoon_v3.log 2>&1 &
```

기존 런처를 먼저 수동 종료하지 마십시오. 새 런처는 코드·프로토콜·완료 결과·B 계획을
확인하고 JMA 자료를 확보한 다음, 확인된 기존 기본 v2 런처에 SIGTERM을 보냅니다.
기존 작업들이 종료됐는지 확인하고 원래의 실행 잠금을 확보한 뒤 남은 B를 재개합니다.
`python3 -u run_v2.py` 같은 상대경로 프로세스도 작업 디렉터리로 확인합니다.
다른 임의의 Python 프로세스를 일괄 종료하지 않습니다.

전환은 무중단 인계가 아닙니다. 학습 재개 파일은 평가 주기 말에 저장되므로 마지막
저장 이후 진행분을 재계산할 수 있습니다. 진행 중인 평가/저장 시간도 다시 들 수
있습니다. 원본 완료 결과와 저장된 체크포인트는 삭제하지 않습니다.

프로세스를 건드리지 않고 사전 점검만 하려면 다음 명령을 사용합니다.
JMA 원본이 없으면 이 단계에서도 다운로드합니다.

```bash
python3 /home/jovyan/swan/swan_bc_typhoon_v3/run_campaign.py
```

이전 설치본 코드가 수정됐거나, 사용자 지정 인자로 실행한 기존 런처이거나,
이미 기존 2021년 평가가 실행 중이면 자동 인계를 중단합니다. 해시 검사를 지워서
우회하지 말고 오류 로그로 설치 상태를 확인하십시오.

## 진행 확인과 재개

```bash
python3 /home/jovyan/swan/swan_bc_typhoon_v3/status.py --watch 10
```

```bash
tail -n 80 /home/jovyan/swan/iclr_bc_typhoon_v3.log
```

중단 후에는 같은 START.sh 명령을 다시 실행합니다. 이미 실행 중인 새 런처가 있으면
잠금 때문에 중복 실행하지 않습니다. 고정된 계획·코드·평가 기준이 달라지면
기존 결과와 섞지 않고 오류를 냅니다. 원래 v2 START.sh를 다시 실행하지 마십시오.

중간 C 두 건 또는 마지막 평가 작업만 남으면 일부 GPU가 쉬는 것은 정상입니다.
GPU 사용률을 채우려고 새 탐색을 만들지는 않습니다. 학습은 최대 8개 단일 GPU 작업,
2021년 추론은 기본 2개 작업을 병행합니다. I/O 부하를 고려한 기본값이며 실행 시작 시
`START.sh --eval-workers 4`로 설정할 수 있습니다.

## 태풍·고파랑 평가 정의

기본 규칙은 `evaluation_protocol.json`에 있으며 실행 시 결과 폴더에 고정합니다.
성능 결과를 본 뒤 기준을 바꿔 같은 실험으로 보고해서는 안 됩니다.

- JMA RSMC Tokyo의 공식 best-track 자료를 사용합니다.
- 경로를 시간별로 선형 보간합니다. 등급은 직전 관측 등급을 적용합니다.
- TS 이상 등급인 중심이 해양 격자 중심에서 400km 이내인 첫 시각부터 마지막 시각까지,
  앞뒤 24시간을 더합니다. 실제 평가 가능한 2021년 시간으로 잘라냅니다.
- 한국어 '태풍'의 넓은 용례를 고려해 이름이 있는 열대저기압 사건을 포함하되,
  JMA 등급 5(TY)에 생애 중 한 번 이상 도달한 사건은 별도로 집계합니다.
- 사건 중첩은 사건별 표에는 각각 포함하지만, 사건 합집합 통계에는 한 번만 셉니다.
- 사건 밖 시간은 '평상시'나 '잔잔한 바다'로 단정하지 않고 `outside_TC_windows`로 표시합니다.
- 이 정의는 재현 가능한 평가 구간 규칙이며 모든 파랑의 원인을 해당 태풍에 귀속하지 않습니다.
  원격 너울이나 온대저기압 사례를 완전하게 포괄한다는 주장도 하지 않습니다.
- 고파랑은 SWAN 정답 Hs가 3m 이상, 5m 이상인 해양 격자·시간을 각각 평가합니다.
  표본이 없으면 오차를 0으로 채우지 않고 빈 값으로 둡니다.
- 3시드 평균과 표본 표준편차(ddof=1)를 보고합니다. 시간별 상관을 무시한 유의성 검정을
  수행하지 않습니다. 시드 표준편차는 사건 표본의 불확실성 구간이 아닙니다.

JMA 자료는 첫 실행 시 공식 ZIP에서 다운로드하고 원본 SHA-256을 고정합니다.
인터넷이 안 되면 아래 공식 ZIP의 텍스트를 내려받아 패키지 폴더의
`jma_besttrack.txt`로 저장한 뒤 다시 실행하십시오. 다운로드 실패 시 기존 학습을
종료하지 않습니다. 자료를 실제로 확보하기 전에는 특정 태풍 목록을 만들어 넣지 않습니다.

공식 원본: https://www.jma.go.jp/jma/jma-eng/jma-center/rsmc-hp-pub-eg/Besttracks/bst_all.zip

형식 설명: https://www.jma.go.jp/jma/jma-eng/jma-center/rsmc-hp-pub-eg/Besttracks/e_format_bst.html

## 출력

학습 결과 요약 위치는 `/home/jovyan/swan/runs/iclr_bc_typhoon_v3/`입니다.

- `selection_fno.json`, `selection_tno.json`, `selection_ffno.json`: 고정된 설정
- `candidate_comparison_*.json`: 파일럿·A·B 후보의 검증 오차, 학습 설정, 기록된 시간
- `selected_9.json`: 실제 2021년 평가에 쓰는 9개 작업과 체크포인트
- `results.csv`: 선택된 9개 실행 결과
- `search/results.csv`: 파일럿·A·B 전체 결과
- `C/`: 새 시드 반복 결과

2021년 출력은 `/home/jovyan/swan/runs/iclr_typhoon_2021_v3/`입니다.

- `events_2021.json`: 경로에서 정의한 사건 기간과 원본 출처
- `selected_2021.json`: 체크포인트 및 학습 정규화 경로
- `summary_2021.csv`: 9개 실행의 연간 성능
- `event_metrics_by_seed.csv`: 연간, 사건 합집합, 사건 밖, 개별 사건의 오차
- `event_metrics_seed_summary.csv`: 위 지표의 모델별 3시드 평균·표준편차
- `models/*/hourly.csv`: 시간별 오차와 고파랑 표본 통계
- `models/*/result.json`: 연간·월간 오차, 평가 시간, GPU 메모리 기록
- `tm_quality_flags.csv`: 정답 Tm 30초 초과 및 정답·예측 음수의 발생 기록
- `models/*/snapshots/*.npz`: 사건별 정답 최대 Hs 시각의 물리 단위 원시 지도, 모든 시드
- `figures/`: 사건별 최대 Hs·오차 시계열과 seed 42의 Hs·Tm·파향 공간 비교

Hs는 m, Tm은 s, 파향 오차는 원형 차이의 도 단위입니다.
공간 그림은 모델 사이에 동일 색상 범위를 사용하며, 정답 극값을 삭제하지 않습니다.
모델의 최대 Hs와 정답 최대 Hs는 위치가 다를 수 있으므로, 정답 최대의 위치·시각에서
예측한 Hs도 별도로 기록합니다. 시계열은 3시드를 모두 표시합니다.

Tm 30초 기준은 품질 점검 표시이며 학습 라벨이나 평가 표본의 자동 제거 기준이 아닙니다.
기존 2019–2020년 t=531의 원본 Tm 문제를 이 코드가 해결했다고 주장하지 않습니다.
2021년 품질 점검은 해당 연도의 새로운 플래그입니다.
